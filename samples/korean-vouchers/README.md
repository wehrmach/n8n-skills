# 한국 지류(종이) 증빙 문서 샘플 PDF

한국의 회계·세무 실무에서 발생하는 **지류(종이) 증빙 문서 50종**을 샘플 PDF로 생성합니다.
OCR·문서분류 모델 학습 데이터, 회계/ERP 시스템 테스트 픽스처, 실무 교육 자료로 사용할 수 있습니다.

> **모든 내용은 가상(架空)입니다.** 상호·성명·번호·금액은 실재하는 개인·법인·기관과 무관하며,
> 모든 문서에 `샘플 SAMPLE` 워터마크와 무효 문구가 인쇄됩니다. 실제 거래·법적 효력이 없습니다.

## 생성 방법

```bash
./fetch_fonts.sh                 # 나눔고딕/나눔명조 내려받기 (최초 1회)
python3 src/generate.py          # 전체 51개 PDF + 통합본 생성
python3 src/generate.py g1 g7    # 특정 그룹만 재생성
```

요구사항: Python 3.8+, Chromium(헤드리스), `pypdf`(통합본 생성 시에만 필요).
Chromium 경로는 `src/generate.py`의 `CHROME` 상수에서 변경할 수 있습니다.

## 구조

```
samples/korean-vouchers/
├── src/
│   ├── common.py          # 폰트·CSS·용지 규격, 금액 한글표기, 사업자번호 체크디지트, 도장/바코드
│   ├── generate.py        # HTML → Chromium print-to-PDF, 목차 생성, 통합본 병합
│   ├── index_meta.py      # 문서별 분류·근거 법령·보관기간 메타데이터
│   └── g1_qualified.py … g9_attach.py   # 그룹별 문서 빌더
├── fonts/                 # 나눔고딕·나눔명조 (git 제외, fetch_fonts.sh로 준비)
├── build/html/            # 중간 산출물 HTML (git 제외)
└── pdf/                   # 최종 PDF
```

용지 규격은 문서 성격에 맞춰 자동 선택됩니다 —
세금계산서 계열은 A4 가로(A4L), 영수증·전표는 80mm 감열지 폭(SLIP),
입금표·간이영수증 등은 A5, 나머지는 A4.

## 데이터 설계

- **거래 스토리 연결**: 견적서(QT-2026-0173) → 발주서(PO-2026-0198) → 거래명세서 →
  세금계산서(공급가액 12,500,000 + 부가세 1,250,000) → 청구서 → 입금표 → 예금거래내역까지
  동일한 금액·번호로 이어지므로, 문서 간 대사(對査) 로직 테스트에 그대로 쓸 수 있습니다.
- **사업자등록번호**: 국세청 체크디지트 알고리즘(가중치 1,3,7,1,3,7,1,3,5)을 통과하는
  가상 번호를 생성합니다. 형식 검증 로직 테스트가 가능합니다.
- **주민등록번호**: 뒷자리를 `******`로 마스킹하여 유효한 번호가 생성되지 않도록 했습니다.
- **금액 한글표기**: `일금 일천삼백칠십오만원정` 형태로 자동 변환합니다.

## 실무 참고 - 적격증빙 수취 기준

- 건당 3만원 초과 지출은 세금계산서·계산서·신용카드매출전표·현금영수증(지출증빙용) 중
  하나를 반드시 수취해야 하며, 미수취 시 증빙불비가산세 2%가 부과됩니다(법인세법 §75의5).
- 건당 3만원 이하는 간이영수증으로 갈음할 수 있습니다(법인세법 시행령 §158②).
- 경조사비는 건당 20만원 이내에서 청첩장·부고장 사본 등으로 증빙합니다(법인세법 시행령 §41).
- 증빙서류는 법정신고기한 종료일부터 5년간 보관해야 합니다(국세기본법 §85의3).

각 문서의 근거 법령과 보관기간은 `pdf/00_증빙문서_목차.pdf`에 정리되어 있습니다.

## 의도적으로 제외한 문서

주민등록등본·인감증명서 등 **개인 신원 확인용 관공서 발급 문서**는 위조 악용 가능성을 고려해
샘플에 포함하지 않았습니다. 사업자등록증·수입신고필증 등 거래 증빙으로 통상 첨부되는 문서는
워터마크와 가상 번호를 적용해 포함했습니다.
